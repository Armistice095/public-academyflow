Une fois AcademyFlow installé et votre profil d'établissement créé, voici les premières étapes recommandées.

## 1. Créez vos premières classes et inscrivez vos élèves

Rendez-vous dans le module **Élèves** pour enregistrer un nouvel élève : informations personnelles, classe, responsables. Cette fiche élève sera réutilisée automatiquement dans les autres modules.

## 2. Enregistrez votre premier paiement

Dans le module **Caisse**, enregistrez un encaissement (frais de scolarité, inscription, etc.). AcademyFlow conserve automatiquement l'élève concerné, le montant, la date, le mode de paiement et l'utilisateur ayant enregistré l'opération.

## 3. Imprimez un reçu

Une fois le paiement validé, un reçu est généré automatiquement. Si vous disposez d'une imprimante thermique de caisse, vous pouvez l'imprimer directement depuis AcademyFlow.

## 4. Consultez vos rapports

Le module **Rapports** vous permet de visualiser l'évolution des encaissements et dépenses, filtrables par période, et de les exporter en PDF ou Excel.
