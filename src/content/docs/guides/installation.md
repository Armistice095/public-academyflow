AcademyFlow est une application de bureau : elle s'installe directement sur votre ordinateur et ne nécessite pas de connexion Internet permanente pour fonctionner.

## 1. Choisissez votre système d'exploitation

Rendez-vous sur la [page de téléchargement](/telecharger) et choisissez l'installeur correspondant à votre ordinateur :

- **Windows** — fichier `.exe`
- **macOS** — fichier `.dmg`
- **Linux** — fichier `.AppImage` ou `.deb`

La page détecte automatiquement votre système d'exploitation et met le bon bouton en avant, mais vous pouvez toujours choisir manuellement.

## 2. Lancez l'installation

**Sur Windows**
1. Ouvrez le fichier `.exe` téléchargé.
2. Si Windows affiche un avertissement SmartScreen, cliquez sur *Informations complémentaires* puis *Exécuter quand même*.
3. Suivez les étapes de l'assistant d'installation.

**Sur macOS**
1. Ouvrez le fichier `.dmg` téléchargé.
2. Glissez l'icône AcademyFlow dans le dossier *Applications*.
3. Au premier lancement, si macOS bloque l'ouverture, allez dans *Réglages Système → Confidentialité et sécurité* et autorisez AcademyFlow.

**Sur Linux**
1. Rendez le fichier `.AppImage` exécutable : clic droit → *Propriétés* → *Autoriser l'exécution*, ou en ligne de commande :
   ```bash
   chmod +x AcademyFlow.AppImage
   ```
2. Double-cliquez sur le fichier pour lancer l'application (ou exécutez `./AcademyFlow.AppImage`).

## 3. Premier lancement

Au premier démarrage, AcademyFlow vous propose de créer le profil de votre établissement (nom, logo, informations de contact). Ces informations seront reprises automatiquement sur les reçus et documents administratifs générés.

## Étape suivante

Une fois l'application installée, passez à l'[activation de votre licence](/guides/activation-licence/).
